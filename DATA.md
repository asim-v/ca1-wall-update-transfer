# Data provenance

## Primary CA1 dataset

Lee, J. Quinn, Keinath, Alexandra, and Brandon, Mark P. (2024). Mouse CA1
Calcium Imaging and Behavioural Dataset in 3x3 Geometric Morph Paradigm.
Zenodo, version v1.

- Dataset DOI: https://doi.org/10.5281/zenodo.13993254
- Paper DOI: https://doi.org/10.1016/j.neuron.2024.10.027

The raw `.mat` files are not redistributed here. The files under
`results/source_data/` are derived analysis summaries and audit artifacts
generated by this project.

## Independent neutral-barrier dataset

Blair, Garrett J. et al. (2023). Hippocampal place cell remapping occurs with
memory storage of aversive experiences.

- Dataset and code DOI: https://doi.org/10.5068/D1ZT2S
- Paper DOI: https://doi.org/10.7554/eLife.80661

The original raw recordings are not redistributed here. The
`blair_barrier_scar.json` file is a derived endpoint summary.

## Redistribution boundary

This repository intentionally excludes:

- raw calcium-imaging recordings;
- raw behavioral tracking files;
- local caches and temporary renderings;
- credentials, tokens, browser state, or personal configuration;
- large regenerable diagnostic images.

Consult the original archives and their terms before redistributing source
data. Derived results should be cited together with both the original studies
and this repository.
